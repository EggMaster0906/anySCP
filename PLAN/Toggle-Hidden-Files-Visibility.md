- 日期：2026-10-30
- 狀態：待使用者檢視；本輪僅建立分支與計畫，不實作功能。
- 基底：本機 `main`，commit `6f9f92f13e0b87b345b7d7d9c6184322a68f2721`。
- 功能分支：`feature/toggle-hidden-files-visibility`。
- 開發 worktree：`/Users/eggmaster/Documents/CodexProject/anySCP-hidden-files`。
- 原工作目錄維持在 Quick Look 分支；本分支不包含 Quick Look 的提交。

## 1. 目標與範圍

1. Explorer 工具列提供「顯示／隱藏隱藏檔案」切換，立即影響目前工作階段。
2. Settings → Explorer 提供「預設顯示／預設隱藏」設定，儲存後重新啟動仍保留。
3. 處理切換造成的選取、焦點、批次操作、空清單及新建項目不可見等問題。

本計畫將範圍定為 SFTP、SCP fallback 與 S3 的物件瀏覽畫面，沿用共用 Explorer 元件。S3 的點號名稱採用相同顯示規則；此處是應用程式的命名過濾，不代表 S3 具有作業系統的隱藏屬性。S3 bucket 選擇清單不套用過濾。

### 隱藏項目的定義

- 以當前清單項目的 `name.startsWith(".")` 判斷，包含檔案、資料夾與符號連結。
- 例如 `.env`、`.git`、`.config` 會被隱藏，`report.v1.txt` 不會。
- 判斷項目本身的名稱，不以完整路徑是否含點號判斷。手動進入 `/.config` 後，仍能看見其下名稱非點號開頭的子項目。
- S3 prefix 的顯示名稱若有結尾 `/`，不影響開頭點號判斷；實作時以 provider 的實際 `name` 格式驗證。
- `.`、`..` 是特殊目錄項目，維持現有後端排除規則。

### 本次不納入

- Windows hidden attribute、macOS Finder flags、`.hidden` 檔案等其他隱藏機制。
- 每台主機的永久偏好、檔名排除樣式、自訂快捷鍵。
- 修改遠端檔案屬性、權限、連線協定或傳輸內容篩選規則。
- 整合尚未合併至 `main` 的 Quick Look 功能。

## 2. 預設值與工作階段切換規則

Settings 的永久預設與 Explorer 的臨時切換分開管理，避免臨時查看 `.env` 就覆寫全域偏好。

| 操作／情境 | 預期行為 |
| --- | --- |
| 尚無設定或設定值無效 | 預設「顯示」，維持現有行為 |
| Settings → Explorer 更改預設 | 儲存全域預設；未手動切換的工作階段跟隨新值 |
| 工具列切換 | 只更新目前工作階段的臨時覆寫值，不寫入全域預設 |
| 已手動切換，再修改 Settings | 該工作階段維持手動選擇；其他未覆寫的工作階段更新 |
| 換目錄、重新整理、切換分頁 | 保留該工作階段的臨時覆寫值 |
| SFTP 切換 sudo 模式 | 即使 session ID 更換、畫面重新掛載，仍保留臨時覆寫值 |
| S3 換 bucket／prefix | 同一工作階段保留臨時覆寫值 |
| 關閉工作階段後重新開啟，或重啟應用程式 | 清除臨時覆寫，重新採用 Settings 預設 |

建議資料模型：

- Settings store：`explorerShowHiddenFiles: boolean`，初始值為 `true`。
- 儲存鍵：`explorer_show_hidden_files`，沿用 `save_setting`／`load_all_settings`。
- session store：`showHiddenFilesOverride: boolean | null`，新工作階段為 `null`。
- 有效顯示值：`showHiddenFilesOverride ?? explorerShowHiddenFiles`。
- 讀取持久化值時只接受 `"true"`／`"false"`；其他值回退為預設顯示。
- 持久化設定尚未載入時，不先以臨時預設值繪出檔案列；顯示局部載入狀態，待 `loaded` 後套用有效值，避免原本設定隱藏卻短暫顯示。
- 工具列的臨時切換在設定載入完成後才可操作。

## 3. 畫面與資料流程

### Explorer 工具列

- 加入可辨識的顯示切換按鈕，沿用現有圖示與按鈕樣式。
- 使用 `aria-pressed` 表示「目前是否顯示隱藏檔案」；tooltip 與 accessible label 說明按下後的動作。
- 不觸發重新列目錄、重新連線或遠端寫入。
- 所有項目都被隱藏時仍可操作此按鈕。

### Settings → Explorer

- 在既有 Explorer 分類新增「Hidden Files by Default」兩段式選項：Show／Hide。
- 說明文字明確指出這是全域預設，工具列切換只影響目前工作階段。
- 沿用目前 Settings 的控制元件及英文產品文案風格。

### 清單過濾

1. 遠端完整清單仍存於 SFTP／S3 session store，不覆寫為過濾後資料。
2. 在 ExplorerView／S3Browser 的資料轉換處，依有效顯示值產生可見項目與已隱藏數量。
3. 共用表格只接收可見項目；排序、鍵盤導覽、全選及新選取所發起的批次操作使用同一份可見清單。
4. 共用一個純函式定義點號判斷及清單過濾，避免 SFTP／S3 規則分歧；以 memo 避免無關 render 重複計算。
5. 額外傳入已隱藏數量／分頁狀態，讓空清單與提示能區分「真的沒有項目」與「目前被過濾」。

保留完整資料供覆寫衝突檢查、原始 entry 查找及傳輸流程使用。顯示過濾的額外成本為對已載入項目的一次線性掃描，沒有額外網路請求。

## 4. 邊界行為

### 4.1 選取、鍵盤與批次操作

- 切換後將選取集合與可見 ID 集合取交集，保留仍可見的選取，移除隱藏項目。
- 以可見集合即時計算實際操作目標與選取數量；不可只等待 effect 清理，留下短暫使用舊選取的機會。
- 被隱藏的 Shift 選取錨點清除；下一次 Shift 選取不沿用失效索引。
- 目前焦點列消失時，焦點回到仍存在的工具列切換按鈕或表格容器，不導向不存在的列。
- 全選、Shift 範圍選取、方向鍵、複製、剪下、下載、刪除及拖曳起始目標均以可見項目為準。
- 針對失去可見性的項目，關閉尚未提交的右鍵選單、重新命名編輯、屬性視窗及刪除確認，避免之後使用舊 entry 執行操作。
- 尚未完成的拖曳互動若包含即將隱藏的項目，取消拖曳並清除事件監聽與視覺狀態。
- 已送交後端的傳輸／操作維持既有執行結果，不因顯示切換而取消或更改內容。

### 4.2 剪貼簿與遞迴操作

- 切換前已明確複製／剪下的剪貼簿內容保留；之後貼上仍使用該明確選取，不將隱藏設定當成剪貼簿篩選器。
- 下載、複製、移動、刪除整個資料夾，或執行既有遞迴權限操作時，保留原有遞迴語意，包含資料夾內的隱藏項目。
- 覆寫／同名衝突檢查仍看完整遠端資料；隱藏既有 `.env` 不應使其被當成不存在。

### 4.3 空清單、計數及 S3 分頁

- 完整清單為空時沿用真正空目錄提示。
- 有資料但全部被過濾時，提示「隱藏項目未顯示」，顯示目前已載入但隱藏的數量，提供顯示隱藏項目的操作。
- 混合清單可顯示隱藏數量提示，避免使用者誤認為資料遺失。
- S3 計數區分「已載入」、「目前顯示」及「目前已載入但隱藏」，不把已載入數量宣稱為 bucket 的總量。
- S3 即使當頁全部被隱藏，只要還有 `nextToken`，仍保留 Load more 並提示尚有未載入資料。
- 不因過濾後沒有可見項目就自動抓完所有頁面；避免破壞現有大 bucket 的逐頁載入設計。
- 切換開關只對已載入清單重新過濾，後續載入的頁面沿用當前有效值。

### 4.4 新建、重新命名與手動路徑

- 新建 `.env`／`.config` 成功後若目前隱藏，顯示成功但被隱藏的提示；不自動變更使用者的顯示選擇。
- SFTP／SCP 將一般項目重新命名為點號開頭且成功後，採相同提示；從選取與焦點移除消失的列。
- 成功提示必須以建立／改名後端操作成功為前提，不能將失敗顯示成成功。
- 手動輸入隱藏資料夾路徑仍可導航；隱藏顯示是列表規則，不是存取限制。
- 在隱藏資料夾內切換顯示不改變當前路徑，不自動跳回上層。
- 上傳、貼上等原有完成回饋維持既有流程；更新後的清單仍遵守顯示規則與隱藏數量提示。

## 6. 實作順序

1. **設定與工作階段模型**：新增預設值、持久化解析及臨時覆寫，驗證 sudo swap 與 bucket 切換。
2. **共用過濾及工具列**：接上 SFTP／SCP／S3 可見清單、切換按鈕與無障礙狀態。
3. **Settings 控制項**：提供 Show／Hide，確認全域預設與手動覆寫的交互規則及延遲載入。
4. **互動邊界**：處理選取、Shift 錨點、焦點、右鍵選單、待確認操作及拖曳。
5. **提示及分頁**：補齊空清單、隱藏數量、新建／改名成功提示與 S3 Load more。
6. **驗證與交付**：執行對應測試與 build，記錄實際結果及未能執行的環境驗證。

| 驗收項目 | 驗證方式 |

| S3 prefix、位於隱藏父路徑內的一般子項目判斷正確 | provider 格式案例與 S3 元件測試 |
| 工具列立即切換且不額外呼叫列目錄 API | SFTP／SCP／S3 元件測試，檢查 invoke 次數 |
| Settings 預設可儲存並重新載入，無值／無效值回退顯示 | settings store 與 Settings UI 測試 |

| 全部被過濾與真正空目錄使用不同文案，按鈕可恢復顯示 | 空清單元件測試 |

| 完整清單與剪貼簿保留，衝突檢查及整目錄傳輸包含隱藏項目 | 呼叫參數與適用的既有真實傳輸測試 |
